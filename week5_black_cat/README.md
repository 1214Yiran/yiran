Concept

The idea came from my own move to New York. The city can feel loud and overwhelming, and I wanted a creature that shows that feeling in a small, readable way. Like a real cat, she:

- "puffs up" in a loud city,
- "relaxes" in nature,
- "stays calm and focused", with glasses on, at work,
- and is "happy and at ease" at a party with her animal friends.

How to Run

With VS Code

1. Open this folder in VS Code (File → Open Folder…).
2. Install the "Live Server" extension (or "p5.vscode", which includes it).
3. Right-click `index.html` and choose "Open with Live Server".

"Without VS Code:" double-click `index.html` to open it in a browser.

p5.js is loaded from a CDN, so you need an internet connection.
